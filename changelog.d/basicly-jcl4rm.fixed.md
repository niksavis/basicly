The dispatch brief now names the skills a unit's own work declares, not only the ones
its persona does. A skill source declares `covers:` (work types, phases) and
`basicly catalog lint` refuses a value the engine cannot dispatch, so the one silent
failure an explicit matcher has — a declaration nothing will ever match — is a refused
commit rather than a skill that quietly never arrives. Six process skills were reachable
only through an author's memory; `worktree-isolation` was reachable by nothing at all.

`basicly usage report` no longer calls never-used skills "culling candidates". The
counter behind that list records `Skill` tool invocations, and a body the dispatch brief
injects is not one, so five of the six skills on it had in fact been delivered — 36
`implementer`, 3 `validator`, 1 `decomposer` and 1 `retrospector` dispatches carried
them. The list is now split into *delivered by a dispatch, never self-invoked* and
*unreachable*, because unexercised and unwanted are different claims.
